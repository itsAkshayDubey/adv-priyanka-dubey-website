# Adv. Priyanka Dubey - Professional Law Website

A modern, responsive website for a legal practice in Chhatrapati Sambhajinagar (Aurangabad), Maharashtra, India.

## Overview

Professional static website built with HTML5, CSS3, and vanilla JavaScript. Features a clean, sophisticated design tailored for legal services with full responsiveness across all devices.

## Key Features

- **Responsive Design** - Optimized for desktop, tablet, and mobile devices
- **Professional UI/UX** - Clean, modern interface with smooth animations
- **Contact Integration** - Direct links for WhatsApp, Email, Phone, and LinkedIn
- **Dynamic Copyright** - Auto-updates year based on IST timezone
- **Legal Compliance** - Bar Council of India compliant disclaimers
- **SEO Optimized** - Proper meta tags and semantic HTML structure
- **Fast Loading** - Minimal dependencies, optimized assets

## Technology Stack

- **HTML5** - Semantic markup
- **CSS3** - Custom properties, Flexbox, Grid
- **JavaScript** - Vanilla JS, no frameworks
- **Fonts** - Google Fonts (Cormorant Garamond, Urbanist)
- **Icons** - SVG vector graphics
